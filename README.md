# Spring JDBC CRUD Operations

This project demonstrates **CRUD operations using Spring JDBC and MySQL**.

## Operations Performed

- Create - Insert student data into the database
- Read - Retrieve student data from the database
- Update - Update existing student data
- Delete - Delete student data from the database

## Technologies Used

- Java
- Spring JDBC
- MySQL
- Maven

## Concept

The project uses Spring JDBC's `JdbcTemplate` to perform database operations with SQL queries.

### CRUD Operations

Create → INSERT
Read   → SELECT
Update → UPDATE
Delete → DELETE
